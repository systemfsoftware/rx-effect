# rx-effect

Bridges RxJS and Effect: turn an Observable into a typed Effect Stream with backpressure and interruption.

## Packages

- [`@systemfsoftware/rx-effect`](packages/rx-effect/README.md): Bridge RxJS and Effect-TS — turn an Observable into a typed Effect Stream with backpressure and proper interruption.

## Install

```bash
pnpm add @systemfsoftware/rx-effect
```

The npm registry lags this repository's sources: `@systemfsoftware/rx-effect` is 1.0.0 on npm and 1.0.3 here. Each package's README describes its current source.
